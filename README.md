# FormaGeo

FormaGeo is a suite of connected geospatial tools for site feasibility,
accessibility analysis and professional GIS workflow automation.

## Applications

- **FormaGeo Site** — Site intelligence and feasibility dashboard
- **FormaGeo Reach** — Accessibility and service coverage analyzer
- **FormaGeo Studio** — QGIS analysis and synchronization plugin

## Technology

- Angular and Nx
- ASP.NET Core
- PostgreSQL and PostGIS
- Python geospatial processing
- QGIS and PyQGIS
- Docker
